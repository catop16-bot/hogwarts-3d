# 霍格沃茲 · 3D 觀覽

在瀏覽器裡以 3D 方式觀覽霍格沃茲城堡與周邊的開放世界：黑湖、禁忌森林、魁地奇球場、活米村……
也可以化身成一名學生，以第三人稱走進入口大廳、大廳與大樓梯塔，或騎著掃帚飛進魁地奇球場。
整體配置以電影後期版（《阿茲卡班的逃犯》到《死神的聖物》）為準，所有模型、材質、天空與天氣都由程式即時生成，沒有使用任何外部美術素材。

> 非官方的同人作品，與 Warner Bros.、J.K. Rowling 無關。

**線上試玩：<https://catop16-bot.github.io/hogwarts-3d/>**（建議用桌機的 Chrome 或 Safari；推到 `main` 會自動重新部署）

## 執行

需要 Node.js 20 以上。

```bash
npm install
npm run dev      # 開發伺服器，預設 http://127.0.0.1:5173
npm run build    # 型別檢查並打包到 dist/（可直接放上 GitHub Pages）
```

## 操作

| 動作 | 方式 |
| --- | --- |
| 旋轉／縮放／平移 | 左鍵拖曳／滾輪／右鍵拖曳 |
| 查看地標介紹 | 點擊建築、浮動標籤或左側清單 |
| 自由飛行 | `F`，WASD 移動、Q／E 升降、Shift 加速、拖曳轉向 |
| 電影運鏡導覽 | `T` |
| 漫遊模式（第三人稱） | `G`，或在地標介紹卡按「在這裡降落」 |
| 暫停時間 | 空白鍵 |
| 顯示／隱藏標籤、介面 | `L`、`H` |

漫遊面板的「前往」選單可以直接跳到任何一個場景。需要按 `E` 進入的都是獨立建造的場景，
從外面看不到，進出時畫面會淡出切換；裡面不能騎掃帚。

湖水夠深時角色會游泳，冬天湖面結冰後可以直接走上去。左上角的面板可以換學院。

下方的時間列可以拖曳時刻與日期、調整時間流速、切換天氣，或按「四季快轉」看一整年的變化。
右上角的「事件」可以直接跳到開學日、萬聖節、聖誕節等時刻。

## 內容

- 30 個可點擊的地標，附中文介紹（位置、故事、電影與原著的差異）
- 依北緯 57° 計算的太陽與月亮軌跡、月相、星空、極光
- 四季：樹葉變色與落葉、積雪、黑湖結冰、南瓜田生長
- 天氣：晴、多雲、陰、霧、雨、雷暴、雪
- 平面倒影的湖水、高度霧、光束、泛光、環境光遮蔽、電影調色
- 小巧思：特快車進站、新生渡湖、貓頭鷹、巨烏賊、魁地奇比賽、會走的鐘樓指針……

## 程式結構

```
src/
  core/         共用 uniform、雜訊、畫質設定
  world/        地形高度函式、地形網格、湖水、樹木
  castle/       建築零件庫 (kit)、材質、城堡與校園各處的建築、可進入的室內 (interiors)
  castle/scenes 室內場景：登記表、燈光池與傳送門 (manager)、家具零件 (kit)、各批場景
  landmarks/    地標資料、拾取與標籤
  environment/  時間、天空、天氣、光照
  fx/           後製特效、會動的事件（火車、小船…）
  camera/       軌道／飛行／導覽鏡頭
  player/       第三人稱角色：程序化人物模型、碰撞、跟隨鏡頭
  ui/           介面
```
